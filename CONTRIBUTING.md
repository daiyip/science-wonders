# Contributing

Corrections and translations are the most welcome contributions: a wrong number, an explanation that misleads, a
missing string in a dictionary. Open an issue with the experiment and a source, or a pull request that cites the
source in its description. To add a language or fix a translation, see "Languages" in the README.
