The Mandelbrot set

Take a number c, start at zero, and square and add c over and over. Either the numbers stay small forever or they run off to infinity. Colour every c by which happens and you get a shape whose edge has new detail however far you zoom.

What you're seeing

Every pixel stands for a complex number c, a point on a plane with a real part across and an imaginary part up. Start with z = 0 and apply the rule z → z² + c again and again. If z stays within distance 2 of zero for as many steps as the iteration limit allows, c counts as part of the Mandelbrot set and is painted black. If z gets further than that, it is certain to run off to infinity, and the pixel is coloured by how many steps that took: dark far away, bright and banded close to the edge.

The picture on the right is a Julia set. It uses the same rule, but with the chosen c held fixed and every pixel used as the starting z. Black points there never escape. The amber path is the orbit of 0: the list of z values 0, c, c² + c, and so on, drawn on both pictures.

Both pictures are computed in background Web Workers so the page stays responsive while you zoom. Every fourth pixel is computed first and blown up into a soft preview; then every pixel is filled in, strip by strip. Moving or zooming throws the unfinished work away and starts again. Two shortcuts save time inside the set: a formula that recognises the main cardioid and the big disc to its left, and a check that stops iterating once an orbit returns exactly to a value it had before.

Zoom far into the edge and the picture eventually turns into flat rectangles. Computers here store numbers as doubles with about 16 significant digits. Once neighbouring pixels are closer together than that precision allows, they are rounded to the same number and get the same colour. With a centre near 1 in size, that happens between about 10¹³× and 10¹⁴× zoom; the Precision readout counts the digits you have left. Deep-zoom programs get past it by computing one orbit at high precision and every other pixel as a small difference from it, a technique called perturbation.

Why it's strange

The rule is one line of arithmetic, yet the edge of the set never gets simpler. Zoom in and you find spirals, seahorse tails and lightning-like branches, and among them tiny copies of the whole set, each slightly different and each with its own copies. The set is also connected: those copies that look like islands are joined to the main body by filaments too thin to draw.

The same black-or-not test on c decides the shape of a whole other picture. Every c inside the set has a Julia set in one piece; every c outside has one that is dust. One point's orbit tells you about infinitely many others.

Pierre Fatou and Gaston Julia studied these iterations by hand around 1918. Benoit Mandelbrot, working at IBM, made the first detailed computer pictures of the set in 1980, and Adrien Douady and John Hubbard proved it is connected in 1982.

The edge is about as wiggly as a curve can be: Mitsuhiro Shishikura proved in 1998 that its fractal dimension is 2, the same as a filled area. The set's area is about 1.5066, known only from large computations. Whether the set is locally connected, which would mean its whole shape is fixed by a simple combinatorial description, is still an open problem.

The math

z0 = 0,  zn+1 = zn² + c
M = { c : |zn| ≤ 2 for every n }

The definition of the Mandelbrot set M. Writing z = x + iy and c = a + ib, one step is x → x² − y² + a and y → 2xy + b, which is exactly what the workers compute for each pixel. If |z| ever exceeds 2 (and |c| ≤ 2), each later step at least doubles the excess, so the orbit must escape; that is why 2 is the radius used for orbits and for the dashed circle. Points that survive the iteration limit are drawn black, so a low limit makes the set look too big.

ν = n + 1 − log₂( ln |zn| )

The smooth escape count used for colouring. A raw step count n jumps by whole numbers and draws hard bands. Once |z| is large, each step roughly squares it, so ln |z| doubles; taking log₂ of ln |z| measures how far through its final step the orbit is. The page iterates each pixel until |z| > 1000 to make this accurate, then colours by √(ν − νmin), where νmin is the smallest count in view, so deep zooms keep their contrast.

Kc = { z0 : zn ↛ ∞ }
c ∈ M  ⇔  Kc connected

The filled Julia set Kc is the set of starting points whose orbits stay bounded for that fixed c, which is what the right-hand picture shows. The point 0 is special because the derivative of z² + c is zero there. Fatou and Julia showed that the fate of this one critical point decides everything: if its orbit stays bounded, Kc is in one piece; if it escapes, Kc is a Cantor set of dust. That is why the same orbit is drawn on both pictures.

c = eiθ/2 − e2iθ/4
θ = 2π p/q  ⇒  period q
δ ≈ 2−52 |c| ≈ 2.2 × 10−16 |c|

The first line traces the edge of the main cardioid: inside it, z² + c has one attracting fixed point, so orbits settle onto a single point. At the angle θ = 2π p/q a bulb is attached whose orbits cycle through q points, which is what the period labels show. The last line is the spacing of double-precision numbers near c. When the pixel size falls below δ, neighbouring pixels share a value and the image breaks into blocks.

Real-world applications

Where iteration and fractals do real work

The set itself is pure mathematics, but the ideas it made famous, repeating a simple rule and finding detail at every scale, turn up across science and engineering.

Electronics

Fractal antennas

An antenna shaped like a fractal packs a long, crinkled conductor into a small space and responds well at several frequencies at once. Nathan Cohen built the first ones in the 1990s, and fractal-style designs have since been used in compact multiband antennas for phones and radios.

In the demo: the edge keeps adding detail as you zoom, so its length has no limit.
Film and games

Fractal landscapes

Loren Carpenter's 1980 short film Vol Libre flew over mountains built by repeatedly subdividing triangles and adding random bumps at each scale. The same approach made the Genesis planet in Star Trek II in 1982, and it is still how many games generate terrain and clouds.

In the demo: structure at every zoom level comes from repeating one rule.
Numerical computing

Solving equations with Newton's method

Newton's method finds roots by repeating a step, just as this page repeats z² + c. Which root it reaches from a given start is decided by the same Julia-set theory Fatou and Julia developed. In 2001 Hubbard, Schleicher and Sutherland used it to give a set of starting points guaranteed to find every root of a polynomial.

In the demo: the Julia panel sorts starting points by where their orbits go.
Physics and biology

Period doubling

Along the real axis the set is the period-doubling cascade of the logistic map, a simple model of population growth. The same cascade, with the same ratio of about 4.669 between steps, was measured by Albert Libchaber in heated liquid helium in 1980 and has been seen in dripping taps, lasers, electronic circuits and heart cells.

In the demo: the bulbs on the real axis have periods 1, 2, 4, 8 going left.
Computing

Teaching and testing parallel computers

Every pixel of the set can be computed independently, so drawing it is a standard first exercise in parallel and GPU programming and a common benchmark. The Computer Language Benchmarks Game, for example, has long included a Mandelbrot program to compare programming languages.

In the demo: several background workers share the strips of each picture.
Imaging

Fractal image compression

Michael Barnsley and Alan Sloan noticed that parts of real photos resemble shrunken copies of other parts, and stored images as the rules that rebuild them. Their company's compression was used for the pictures in Microsoft's Encarta encyclopedia in 1993, though faster methods such as JPEG won out.
